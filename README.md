# Solution-for-Industry-Knowledge-Hub-Platform
Solution for Industry Knowledge Hub Platform


โปรเจค์นี้เป็นการทำ RAG สำหรับการทำ Knowledge Hub Platform โดยชุดข้อมูลที่อยู่ภายใน DB คือหนังสือ หลักสูตรความมั่นคงปลอดภัยระบบคลาวด์ โดยสำนักงานคณะกรรมการรักษาความมั่นคงปลอดภัยไซเบอร์แห่งชาติ 


วิธีการทำงานเป็นการแบ่งงานเป็น 2 ส่วนโดยต้อง Run 2 files พร้อมกันเพื่อการทำงาน

1.) main.py เป็นหน้าต่างหลักในการสั่งทำงานทั้งหมดของระบบ โดยมีการทำงานหลักทั้งหมด 3 ส่วน คือ

1.1) Chatbot

1.2) การรับข้อมูลเข้า DB โดย Input PDF/PNG/JPG

1.3) Block/Post เป็นการโพสความรู้และเนื้อหาและสามารถสรุปได้ด้วย LLM


2.) server_local.py หน้าที่ในการประมวลผลของ Model Embedding & Reranking เพื่อแยกส่วน Model ที่ต้องใช้การประมวณผลที่หนักออกมาจากระบบหลัก โดยส่วนนี้จะทำงานอยู่บน Local และใช้การดึง API จาก FastAPI และ Ngrok
